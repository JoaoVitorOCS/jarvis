# Músicas

Coloque aqui as faixas que você quer usar nos reels (`.wav` ou `.mp3`), de preferência **instrumentais** (sem voz cantada),
porque o texto na tela já disputa a atenção. As músicas não vão para o git.

No `reel.json`: `"musica": "kit/musica/nome.wav"` e, se quiser começar na parte forte, `"musica_inicio": 18.5` (segundos).
A mixagem coloca a música 6 dB abaixo dos efeitos e normaliza o master em `"lufs"` (padrão −16; mais baixo = −20, −24).

Música com direitos autorais embutida no vídeo pode ser silenciada pelo Instagram. Para usar o áudio licenciado com o nome
aparecendo no post, publique pelo app e escolha a música lá.
